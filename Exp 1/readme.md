# 📱 Social Media Post Composer

## Project Description

A React.js based dynamic post composer application that allows users to create posts for multiple social media platforms with platform-specific validation.

The application provides real-time feedback, character limit checking, image preview, draft saving, and live post preview.

---

# Features

## Multi Platform Support

Supported platforms:

- Facebook
- Instagram
- Twitter
- LinkedIn


## Post Creation

Users can:

- Write posts
- Upload images
- Add emojis
- Add hashtags
- Preview posts before publishing


## Validation System

The application provides:

- Character counter
- Remaining character count
- Platform-specific character limits
- Warning messages
- Error messages


## Draft Saving

Posts are automatically saved using browser localStorage.

Users can continue editing after refreshing the page.


## Responsive Design

The UI works on:

- Desktop
- Tablet
- Mobile devices
