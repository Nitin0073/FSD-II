RESTful API Design and Global Exception Handling in Spring Boot

Two linked experiments treated as one build: a layered Spring Boot service for the Dispatch post-composer backend, then the exception handling, correlation IDs, and logging that make it observable in production.

Aim

To design and implement RESTful APIs using Spring Boot with proper validation, standardized responses, and scalable architecture.

Objective

  • Understand REST API design principles
  • Implement CRUD APIs using Spring Boot
  • Enforce consistent request-response structures
  • Apply validation using Bean Validation
  • Enable secure cross-origin communication

Theory

REST treats data as resources accessed through standard HTTP methods — GET, POST, PUT, DELETE. Spring Boot organises this into a layered architecture: the Controller layer handles HTTP requests, the Service layer holds business logic, and the Repository layer talks to the database.

A well-designed API keeps communication stateless, follows a consistent URI structure, and returns a standardized response shape. Bean Validation annotations — @NotNull, @NotBlank, @Size — check incoming data before it reaches the service layer, and CORS configuration lets the Dispatch frontend, running on a different origin, call the API safely.

Implementation Overview

  • Project structure with Controller / Service / Repository layers
  • CRUD endpoints for posts, plus a scheduling endpoint
  • Validation annotations on the request DTO
  • A single ApiResponse<T> envelope for every response
  • CORS configuration scoped to the Dispatch client origin

Aim

To implement global exception handling and structured logging for building robust and observable backend systems.

Objective

  • Handle exceptions centrally using @ControllerAdvice
  • Implement logging for request tracking
  • Use correlation IDs for tracing requests
  • Improve observability and debugging

Theory

Handling exceptions inside every controller duplicates code and produces inconsistent error shapes. @ControllerAdvice centralises that into one place, so every failure — validation, missing resource, or an unexpected fault — comes back through the same error envelope.

Filters and interceptors sit in front of that logic as middleware, useful for logging, authentication, and request modification. A correlation ID, attached per request through MDC (Mapped Diagnostic Context), threads through every log line for that request, so a single failure can be traced end to end even across a distributed system.

Implementation Overview

  • @ControllerAdvice for centralised exception handling
  • Custom exception classes per failure type
  • A logging filter that times each request
  • Correlation ID generation and propagation via MDC
  • One error response shape across the API

@RestController
@RequestMapping("/api/posts")
public class PostController {

    private final PostService service;

    public PostController(PostService service) { this.service = service; }

    @GetMapping
    public ApiResponse<List<PostDto>> list() {
        return ApiResponse.ok(service.findAll());
    }

    @PostMapping
    @ResponseStatus(HttpStatus.CREATED)
    public ApiResponse<PostDto> create(@Valid @RequestBody CreatePostRequest req) {
        return ApiResponse.ok(service.create(req));
    }

    @PutMapping("/{id}")
    public ApiResponse<PostDto> update(@PathVariable UUID id, @Valid @RequestBody UpdatePostRequest req) {
        return ApiResponse.ok(service.update(id, req));
    }

    @DeleteMapping("/{id}")
    @ResponseStatus(HttpStatus.NO_CONTENT)
    public void delete(@PathVariable UUID id) {
        service.delete(id);
    }

    @PostMapping("/{id}/schedule")
    public ApiResponse<PostDto> schedule(@PathVariable UUID id, @Valid @RequestBody ScheduleRequest req) {
        return ApiResponse.ok(service.schedule(id, req.scheduledAt()));
    }
}
@Service
public class PostService {

    private final PostRepository repository;

    public PostService(PostRepository repository) { this.repository = repository; }

    public PostDto create(CreatePostRequest req) {
        Post post = new Post(req.title(), req.content(), req.platform());
        return PostDto.from(repository.save(post));
    }

    public PostDto update(UUID id, UpdatePostRequest req) {
        Post post = repository.findById(id)
            .orElseThrow(() -> new PostNotFoundException(id));
        post.applyUpdate(req);
        return PostDto.from(repository.save(post));
    }

    public void delete(UUID id) {
        if (!repository.existsById(id)) throw new PostNotFoundException(id);
        repository.deleteById(id);
    }

    public PostDto schedule(UUID id, Instant scheduledAt) {
        Post post = repository.findById(id)
            .orElseThrow(() -> new PostNotFoundException(id));
        post.schedule(scheduledAt);
        return PostDto.from(repository.save(post));
    }
}
public record ApiResponse<T>(
    boolean success,
    T data,
    ApiError error,
    Instant timestamp,
    String correlationId
) {
    public static <T> ApiResponse<T> ok(T data) {
        return new ApiResponse<>(true, data, null, Instant.now(), MDC.get("correlationId"));
    }

    public static ApiResponse<Void> error(String code, String message) {
        return new ApiResponse<>(false, null, new ApiError(code, message),
            Instant.now(), MDC.get("correlationId"));
    }
}
@RestControllerAdvice
public class GlobalExceptionHandler {

    private static final Logger log = LoggerFactory.getLogger(GlobalExceptionHandler.class);

    @ExceptionHandler(MethodArgumentNotValidException.class)
    @ResponseStatus(HttpStatus.BAD_REQUEST)
    public ApiResponse<Void> onValidation(MethodArgumentNotValidException ex) {
        log.warn("validation failed: {}", ex.getMessage());
        return ApiResponse.error("VALIDATION_ERROR", ex.getMessage());
    }

    @ExceptionHandler(PostNotFoundException.class)
    @ResponseStatus(HttpStatus.NOT_FOUND)
    public ApiResponse<Void> onNotFound(PostNotFoundException ex) {
        log.warn("post not found: {}", ex.getMessage());
        return ApiResponse.error("POST_NOT_FOUND", ex.getMessage());
    }

    @ExceptionHandler(Exception.class)
    @ResponseStatus(HttpStatus.INTERNAL_SERVER_ERROR)
    public ApiResponse<Void> onUnexpected(Exception ex) {
        log.error("unhandled exception", ex);
        return ApiResponse.error("INTERNAL_ERROR", "Something went wrong. Try again shortly.");
    }
}
@Component
public class CorrelationIdFilter extends OncePerRequestFilter {

    private static final Logger log = LoggerFactory.getLogger(CorrelationIdFilter.class);

    @Override
    protected void doFilterInternal(HttpServletRequest req, HttpServletResponse res, FilterChain chain)
            throws ServletException, IOException {
        String cid = Optional.ofNullable(req.getHeader("X-Correlation-Id"))
            .orElse(UUID.randomUUID().toString().substring(0, 8));
        MDC.put("correlationId", cid);
        long start = System.currentTimeMillis();
        try {
            chain.doFilter(req, res);
        } finally {
            log.info("{} {} - {} ({}ms)", req.getMethod(), req.getRequestURI(),
                res.getStatus(), System.currentTimeMillis() - start);
            MDC.clear();
        }
    }
}
@Configuration
public class CorsConfig implements WebMvcConfigurer {

    @Override
    public void addCorsMappings(CorsRegistry registry) {
        registry.addMapping("/api/**")
            .allowedOrigins("http://localhost:5173")
            .allowedMethods("GET", "POST", "PUT", "DELETE")
            .allowedHeaders("*")
            .allowCredentials(true);
    }
}
